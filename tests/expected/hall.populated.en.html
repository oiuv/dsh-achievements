How progress works

Capability progress uses tool results without an error flag. A build loop means read → modify → command in one session; it does not certify that tests passed. Optional tools must be enabled in DSH. XP is awarded once per achievement.

Counts include stored sessions available to this DSH profile. Inherited fork history is excluded.

Stored locally: counters and achievement progress. No prompts, file contents or tool results are copied.
